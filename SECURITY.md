# Security policy

Do not publish reports, data, or assets that contain sensitive information. GitHub Pages is public hosting, UUID links are unlisted, StatiCrypt encrypts HTML only, and expiry is delayed cleanup.

For a vulnerability in this repository, use GitHub's private vulnerability reporting feature if it is enabled for the repository. Otherwise, contact the repository owner through their GitHub profile before sharing exploit details. Do not post credentials, private reports, or exploit instructions in a public issue.
